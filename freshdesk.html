KB Sync for Freshdesk

Write your solution articles in Confluence. KB Sync publishes them to your Freshdesk knowledge base and keeps them up to date. Every edit reaches Freshdesk within seconds.

KB Sync for Freshdesk works like KB Sync for Zendesk: the same page trees, layouts, formatting and limits. This page covers what's different.

Set up (5 minutes)

You need to be a Confluence site admin, and have a Freshdesk API key of an admin, or of an agent who can publish solution articles.

  1. Install KB Sync for Freshdesk from the Atlassian Marketplace.
  2. Open its settings: admin.atlassian.com > Apps > Sites > your site > Connected apps > KB Sync for Freshdesk > ⋯ > Configure.
  3. Get your API key: in Freshdesk, click your profile picture (top right) > Profile settings > View API key.
  4. On the settings page, enter your Freshdesk address (the acme in acme.freshdesk.com) and paste the API key. Click Connect Freshdesk. KB Sync checks the key against your knowledge base straight away.
  5. Under Add a page tree, paste a link to a Confluence page or folder, choose the options, and click Add and sync.

The API key is kept in Atlassian's encrypted storage, is never shown again, and is only used for Freshdesk's knowledge base API. Disconnect deletes it. You can also reset the key in Freshdesk at any time; then connect again with the new key.

Differences from the Zendesk version

  • Who can see the articles is set per folder in Freshdesk: Everyone, Signed-in users or Agents only. KB Sync applies your choice to every folder it manages.
  • Article order: Freshdesk's API doesn't let apps set the order of articles or folders, so Freshdesk's own ordering is used.
  • Images also appear under "Attachments" at the bottom of each article in the portal, because Freshdesk lists every file uploaded to an article.
  • Drafts mode: when you choose drafts and later publish an article in Freshdesk, further Confluence edits are saved as a draft on that article for you to review and publish. With Publish straight away, every edit goes live.
  • One knowledge base: the app publishes to the main portal of the Freshdesk account you connect.

Troubleshooting

You seeDo this
"Freshdesk didn't accept that API key"Copy the key again from Profile settings > View API key, with no spaces. If you reset the key in Freshdesk, the old one stops working.
"That API key's agent can't manage the knowledge base"Use the key of a Freshdesk admin, or of an agent whose role can publish solution articles.
"KB Sync can't reach … .freshdesk.com"Enter the address Freshdesk gave your account (acme.freshdesk.com), even if your portal uses a custom domain.
Syncing a large tree is slowFreshdesk limits API calls per minute by plan (trial accounts: 50 per minute). KB Sync waits and continues automatically.
An edit isn't visible in the portalCheck the tree is set to Publish straight away. In drafts mode, publish the article in Freshdesk.

For everything else, see the FAQ and troubleshooting pages; they apply to both versions.
